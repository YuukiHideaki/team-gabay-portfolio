Mobile app prototype

Asukal Check

Team Project
See details

Asukal Check is an interactive mobile health prototype focused on making blood sugar tracking feel simple, calm, and readable. The flow helps a user log readings, review weekly glucose trends, and receive practical lifestyle tips without overwhelming them with too much medical-looking information at once.

Made with: Figma, HTML, CSS, JavaScript

Blood Sugar Tracking Health Habits Lifestyle Guidance
  • Dashboard screen for current status, recent readings, and a seven-day average.
  • Trends, Tips, and Profile routes that make the prototype feel like a real mobile app flow.
  • Localized guidance about meals, walking after eating, and checkup reminders.

Student dashboard prototype

StudyBase

By John Rolly A. Calipusan
See details

StudyBase is a student productivity prototype designed as a central hub for everyday academic life. It combines class schedules, assignment deadlines, finance tracking, savings, grades, and study planning into one dashboard so students can quickly understand what needs attention.

Made with: Figma, HTML, CSS, JavaScript

Academic Planning Budget Tracking Grade Overview
  • Dashboard cards summarize due tasks, classes today, budget left, savings, and overall GPA.
  • Planner views organize coursework into due dates, priority tags, and assignment groups.
  • Finance screens help track income, spending categories, and student budget status.
03

Web utility project

File Vault

By James Enrico Anore
See details

File Vault is a straightforward web utility for collecting and browsing document resources. The project focuses on a simple upload flow, visible file cards, and search behavior that helps users find saved PDF files without digging through folders manually.

Made with: HTML, CSS, JavaScript

Document Vault File Search Resource Library
  • Multiple document upload flow for keeping school resources in one place.
  • Search input filters filenames so users can quickly find the right file.
  • Preview layout keeps uploaded PDFs readable, organized, and easy to scan.
