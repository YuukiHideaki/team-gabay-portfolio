Web Design Philosophy

How we shaped this portfolio

01

Clean academic showcase

We kept the theme light, direct, and readable so the portfolio feels like a clear presentation of our class work.

02

Interaction over decoration

Instead of glass effects, we used small transitions, hover states, and page motion to make the site feel active.

03

Beginner-friendly structure

The layout uses simple pages, reusable classes, and understandable code so the design can keep improving with us.
